FastGrab: Frequently Asked Questions

Quick answers for launching the extension, downloading files, upgrading Flickr results, and troubleshooting pages that behave differently.

Need the short version?

FastGrab Image Downloader is designed to stay lightweight until you intentionally activate it, and most downloads are organized automatically using the source page title. The sections below cover the most common questions users run into first.

Getting Started

Getting Started

Why do I need to click the extension icon every time I want to use Fast Grab or open the gallery?

This is a security and performance feature built into your web browser. To protect your privacy and stop your computer from slowing down, browsers do not let extensions secretly run in the background on every single webpage you visit.

Clicking the extension icon wakes it up and gives it temporary permission to look for images on that specific page.

How do I use Fast Grab without the Add-on window taking up my screen?

You can use the green Minimize (_) button! Minimizing hides the main window but leaves a small, floating icon on your screen. While minimized, the extension is still "awake," allowing you to use Right-Click saves or Fast Grab instantly.

Note: If you click the red Close (X) button, it completely shuts down the extension for that page, meaning Fast Grab and Right-Click shortcuts will stop working until you reopen it.

Where do my downloaded images go?

Whenever you download an image or a batch of images, they are sent to the folder specified in your web browser’s download settings.

To keep things organized, the extension automatically places your downloaded images inside a new folder, or a ZIP file, named after the title of the website you extracted them from.

What is a ZIP file and why did it download one?

If you select multiple images and click download, the extension bundles them all together into a single ZIP archive. This is much faster than making your browser download many separate files one by one.

Once it is on your computer, you can usually just double-click the ZIP file to open it and access all your pictures.

Settings & Features

Settings & Features

Which settings are best to use?

For most users, the Default Settings are a great starting point because the extension is pre-configured to be fast and reliable out of the box.

However, FastGrab Image Downloader is a powerful tool. Reading the User Guide will show you exactly what each toggle does so you can tune it to your workflow. If you are not sure what an advanced setting means, it is usually safest to leave it on the default option until you need it.

How do I get the highest resolution images from Flickr?

When you open the gallery on Flickr, the extension initially loads fast preview thumbnails so you can browse smoothly. To get the massive 4K or Original resolution files, click the Upgrade button in the gallery, or enable the Automatic Upgrade setting.

Upgrading takes a moment because the extension is invisibly hunting down the true high-resolution files from Flickr’s code. Once they are upgraded in the gallery, clicking Download will instantly save the massive files.

If you use the Right-Click or Fast Grab features with the upgrade setting enabled, the extension will do this hunting process automatically before saving.

Troubleshooting

Troubleshooting

What do I do if the extension doesn’t work for a particular website?

Some websites use highly complex code or custom layouts that make it difficult for the extension to find the images.

First step: try clicking on the image directly on the website to open it fully on your screen, and then try using the extension again.

Next step: if it still does not work, please submit a report on our GitHub Support Page. Include the link to the website that is not working, and we will do our best to update the extension to support it as quickly as possible.

Why do some images say “Source size unavailable”?

When the extension finds a high-quality image, it tries to read the dimensions, such as 1920x1080, so you can see exactly how big it is. Occasionally, the website hides those numbers in its code.

The image will still download perfectly fine in high quality. The extension just could not read the exact pixel size beforehand.
