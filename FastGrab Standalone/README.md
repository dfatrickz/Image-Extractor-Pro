FastGrab lets you download images directly from the page with a single click.

FastGrab is a lightweight image downloader designed for quick saves without opening a gallery or extra menus.

Features

Hover download button: Move your pointer over an image to show a download button on the page.
High-resolution downloads: On supported sites such as Flickr, FastGrab can request the original or highest-resolution image instead of the preview image.
Direct image upgrades on supported sites: On some sites, FastGrab can resolve image links to a larger version when one is available.
Works with harder-to-save images: FastGrab can detect images used in CSS backgrounds, frames, and other page layouts where normal image saving is less convenient.
Context menu support: Right-click an image and choose Save Image via FastGrab.

How it works
FastGrab activates when you turn it on for the current page. When you use FastGrab on a supported image, it may request the image file or the site’s image URL needed to retrieve a higher-resolution version. It does not send image data to our own servers.
