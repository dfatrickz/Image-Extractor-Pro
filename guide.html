Image Extractor Pro Guide

Welcome! This guide explains all the features and settings available in the extension.

Download Preferences

Default Download Mode

What it does: Sets whether you want to download a single compressed ZIP file containing all images, or download each image individually.

When to use it: ZIP is usually faster, cleaner, and recommended. Individual files are good if you are only downloading 2 or 3 images.

Subfolder Name

What it does: Automatically creates a named folder inside your computer's default Downloads folder to store the extracted images.

When to use it: Great for organizing large batches so they don't clutter your main downloads folder (e.g., naming it "Vacation_Photos").

File Naming Scheme

What it does: Determines what the files are called on your computer. "Original Name" tries to keep the source name. "Sequential" renames them to image_1, image_2, etc.

When to use it: Sequential is very helpful if the original website uses messy, random strings of numbers and letters for their file names.

Image Origin

What it does: Displays a small badge or text under each extracted image in the gallery showing exactly where it was found in the website's code (e.g., standard image, CSS background, or a hidden data attribute).

When to use it: Helpful for web developers or advanced users who are curious about how a specific website is building its pages or hiding its photos.

Safety & Behavior

Lazy Load Bypass (Auto-Scroll)

What it does: Many modern websites only load images as you scroll down the page (called "Lazy Loading"). By default, the extractor will automatically scroll the page for you to wake up those hidden images before extracting.

When to use it: Keep this ON if you want the scanner to automatically scroll and find everything. Turn it OFF if you want the scanner to skip scrolling and run instantly (which is faster, but will only extract images currently visible on your screen).

Disable website image controls

What it does: Sites like Instagram or Flickr often place invisible "shields" over their photos or hijack your mouse to stop you from right-clicking or saving them.

When to use it: Keep this enabled. It forcefully restores your browser's native Right-Click menu and removes invisible overlays so you can use the Fast Grab feature.

Enable Fast Grab

What it does: Whenever you hover your mouse over an image on any website, a small blue download button will appear in the corner of that picture. Clicking it will instantly find the highest resolution version and download it to your computer.

When to use it: Highly recommended for quick, single-image downloads without needing to open the full review gallery.

Persistent Floating Icon

What it does: Injects the floating Image Extractor icon on every website automatically.

When to use it: If you use the tool frequently, keep this on. If you only want the tool to appear when you click the puzzle piece in your browser toolbar, turn it off.

Show Floating Icon on Pages

What it does: Displays or hides the floating button inside the webpage.

When to use it: Turn this off if you find the button distracting and prefer to only launch the extractor from your browser's extension menu.

Start Minimized

What it does: When enabled, the extension opens as just a small floating button. When disabled, the full extraction panel opens immediately when the page loads.

When to use it: Keep this checked to prevent the large panel from popping up and blocking your view every time you navigate to a new page.

Enable automatic duplicate checking

What it does: Uses an advanced visual scanner to find and hide exact duplicate images before you even open the review gallery.

When to use it: Highly recommended for messy websites like Pinterest, Tumblr, or blogs that repeat the same thumbnail multiple times.

Rate Limit / Delay per image (ms)

What it does: Adds a tiny artificial pause (in milliseconds) between each download when you are downloading a large batch of individual files.

When to use it: If a website is blocking your downloads because you are requesting files too fast, set this to 500 or 1000 to slow the extension down and look more like a human.

Individual Download Warning Threshold

What it does: Pops up a confirmation warning before you accidentally download a massive amount of individual files.

When to use it: Leave this around 30. It prevents you from accidentally freezing your browser by downloading 500 individual files at once instead of using the safer ZIP Archive mode.

Appearance

Sticky Toolbar

What it does: Keeps the gallery's top menu (with the Download and Select All buttons) permanently pinned to the top of your screen while you scroll down through your extracted images.

When to use it: Highly recommended to keep this enabled so you don't have to scroll all the way back to the top to download your selections.

Window Size

What it does: Changes the physical size (Small, Medium, Big) of the floating extractor panel on the webpage.

Theme

What it does: Forces the extension to use Light mode, Dark mode, or automatically follow your computer's system settings.

Theme Style

What it does: Adjusts the visual flair of the review gallery. You can choose between a Minimal look, Standard, or Rich (which adds shadows and gradients).

Images per page

What it does: Paginates the review gallery, breaking it up into multiple pages if you extract a massive amount of images.

When to use it: If you extract 2,000 images and the gallery feels slow or laggy to scroll through, set this to 100 or 200 to speed up performance.
